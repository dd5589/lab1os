# Лабораторная работа №1. Мониторы

## Описание

Реализован монитор для синхронизации двух потоков: поставщика (Producer) и потребителя (Consumer).

Поставщик с задержкой в одну секунду создаёт событие и передаёт его потребителю. Потребитель ожидает появления события, получает данные, обрабатывает их и выводит результат на экран.

Программа создаёт и обрабатывает 5 событий.

## Используемые технологии

- C (C11)
- POSIX Threads (`pthread`)
- GCC
- MSYS2 UCRT64

## Реализация

Для организации монитора используются следующие компоненты:

- `pthread_mutex_t` — мьютекс для защиты общих данных.
- `pthread_cond_t` — условная переменная для ожидания события.
- `ready` — признак готовности события.
- `stopping` — признак завершения работы поставщика.
- `void *data` — указатель на передаваемые данные.

### Поток-поставщик

1. Ожидает одну секунду.
2. Захватывает мьютекс.
3. Проверяет, обработано ли предыдущее событие.
4. Создаёт объект события и записывает его адрес в монитор.
5. Устанавливает `ready = 1`.
6. Выводит сообщение об отправке события.
7. Вызывает `pthread_cond_signal()` для уведомления потребителя.
8. Освобождает мьютекс.

### Поток-потребитель

1. Захватывает мьютекс.
2. Проверяет значение `ready`.
3. При отсутствии события ожидает уведомления через `pthread_cond_wait()`.
4. Получает указатель на объект события.
5. Обрабатывает данные и выводит результат.
6. Освобождает память и сбрасывает `ready = 0`.
7. Освобождает мьютекс.

После отправки всех событий поставщик устанавливает `stopping = 1` и вызывает `pthread_cond_broadcast()`, чтобы потребитель мог завершить работу.

## Передача данных

Для хранения события используется структура:

```c
typedef struct {
    int number;
    int value;
} Event;
```

Объект создаётся динамически с помощью `malloc()`. Его адрес записывается в `void *data` и передаётся потребителю.

После обработки объекта потребитель освобождает выделенную память с помощью `free()`.

Таким образом, передаётся указатель на объект, без сериализации данных.

## Сборка и запуск

Для сборки используется GCC из MSYS2 UCRT64.

### 1. Установка компилятора

Открой терминал MSYS2 UCRT64 и выполни:

```bash
pacman -S --needed mingw-w64-ucrt-x86_64-gcc
```

### 2. Переход в папку проекта

Создай папку и перейди в неё в терминале

```bash
cd /c/Monitor-papka
```

### 3. Компиляция

```bash
gcc -std=c11 -Wall -Wextra -pthread monitor.c -o monitor.exe
```

### 4. Запуск

```bash
./monitor.exe
```

## Результат

Реализован монитор с двумя потоками, обеспечивающий безопасную передачу и обработку событий. Использование мьютекса и условной переменной позволяет сохранить порядок сообщений и организовать ожидание без активной проверки состояния.
